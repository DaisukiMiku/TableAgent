# Table Report

Use this skill after the computation is complete and validated. It turns spreadsheet results into a concise business-facing report.

## Report Shape

Prefer this structure for business table analysis:

1. One-sentence conclusion.
2. Small result table with units, values, ranks, changes, or flags.
3. Key observations:
   - strongest/worst performers
   - changes over time
   - outliers
   - risk thresholds
4. Recommended next actions.
5. Evidence/validation note.

## Style

- Keep numbers traceable; do not over-round unless the user asks.
- For ratios, show either full precision or 4-6 decimals consistently.
- Separate facts from interpretation.
- Avoid pretending a causal explanation is in the data if the sheet only supports descriptive analysis.
