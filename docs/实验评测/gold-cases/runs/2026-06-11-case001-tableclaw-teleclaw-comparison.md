## 数据难点

这条 case 的关键不是单元格抽取，而是排名计算前的数据语义处理。

| 难点 | 说明 |
| --- | --- |
| 排名列为空 | 表内 `应收占收比-排名`、`产数应收占收比-排名` 等列没有可直接读取的排名结果，需要自行排序。 |
| 百分比编码混用 | 同一指标列中，有些单元格用小数表达百分比，有些单元格直接写百分数数值。 |
| 原始数值排序会错 | 例如 `0.0902` 的业务含义是 `9.02%`，如果直接与 `7.33` 比较，会误判 `0.0902 < 7.33`。 |
| cohort 需要重排 | 200亿省排名不是读取原排名，而是先筛选 `2023年总收入 >= 200` 的省份，再在子集内排序。 |

本 case 需要的归一化规则：

```text
对于占比/比率/率等百分比语义指标：
若 0 < abs(value) <= 1，则按 value * 100 转为百分数数值；
否则保留原值作为百分数数值。
```

示例：

| 原始值 | 归一化后 | 含义 |
| ---: | ---: | --- |
| 0.0902 | 9.02 | 9.02% |
| 0.31 | 31.00 | 31.00% |
| 7.33 | 7.33 | 7.33% |
| 23.51 | 23.51 | 23.51% |

### TableClaw 关键实现点

`tableclaw_rank` 承担了本 case 中最容易出错的结构化计算：

- 定位指标列。
- 判断指标是否属于百分比/占比/比率类。
- 对 `0 < abs(value) <= 1` 的百分比类数值执行 `ratio_to_percent`。
- 构造可排序 records。
- 按从低到高计算实体排名。
- 如果存在 cohort，如 `200亿省`，则定位 cohort 指标并过滤。
- 返回 `target.rank` 和 `cohort_target.cohort_rank`。

## 差异分析

### TableClaw 特点

- 路径短：主要是 `retrieve -> inspect -> extract_series -> rank`。
- 成本低：本 case 耗时和 token 明显少于 TeleClaw。
- 规则可复用：混合百分比归一化、实体排名、cohort 排名由工具统一处理。
- 可观测：评测中可以直接统计 `tableclaw_rank` 是否被调用。
- 风险：如果工具对字段语义或 cohort 条件理解错误，错误会被稳定执行。
- 风险：模型仍可能调用一些非最终问题所需的排名，例如对应收总额和产数应收总额做核查 ranking。

### TeleClaw 特点

- 自诊断链条完整：主动发现排名列为空、百分比编码混用、单元格格式不一致。
- 验证过程显性：通过 `number_format` 和公式反算确认 `0.0902`、`7.33` 的业务含义。
- 对未知表结构适应性强：即使没有专门 rank 工具，也能临时构造 pandas/openpyxl 流程。
- 成本高：同一问题耗时约为 TableClaw 的 5.66 倍，token 约为 3.74 倍。
- 稳定性风险：依赖模型每次都能临场发现混合百分比编码；同类问题不保证每次都走到相同诊断路径。
- 执行噪声：最后出现一次无效的 `report_final_files` 调用。

## 失败模式记录

这个 case 的常见错误路径是直接用原始数值排序：

```text
湖南 0.0902
安徽 0.117
广东 0.1603
福建 0.2391
四川 7.33
...
```

该排序会得到错误结论：

| 指标 | 原始数值排序会得到 | 正确结果 |
| --- | ---: | ---: |
| 应收占收比全国排名 | 第 5 | 第 1 |
| 应收占收比 200亿省排名 | 第 3 | 第 1 |
| 产数应收占收比全国排名 | 第 8 | 第 4 |
| 产数应收占收比 200亿省排名 | 第 6 | 第 4 |

错误原因不是找错表，也不是四川行抽值错误，而是没有在排名前统一百分比量纲。

## 实验结论

本 case 中，当前 TableClaw 和当前 TeleClaw 都给出了正确答案。

两条正确路径的差异如下：

```text
当前 TeleClaw:
读取文件区 -> pandas/openpyxl 探索 -> 发现排名列为空
-> 发现百分比混合编码 -> 公式反算验证 -> 归一化排序 -> correct

当前 TableClaw:
retrieve -> inspect -> extract_series -> tableclaw_rank
-> 工具内完成百分比归一化、cohort 过滤和排序 -> correct
```

这说明 case001 的关键能力是：

- 从问题中识别出“抽值 + 排名 + cohort 排名”任务。
- 找到 2024 年 3 月省级应收总额表。
- 发现或处理排名列为空。
- 对百分比类字段做量纲归一化。
- 按 `2023年总收入 >= 200` 构造 200亿省 cohort 并重新排名。

在这条 case 上，TeleClaw 展示了更显性的临场诊断过程；TableClaw 通过专用 rank 工具用更短路径完成同一计算。
